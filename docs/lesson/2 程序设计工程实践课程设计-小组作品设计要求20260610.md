# 《充电控制系统》设计要求

充电系统由两部分组成：控制器和采集器。控制器和采集器之间使用基于串口的Modbus协议通信。

## 充电控制器功能：

1. 能够检测用户插枪和刷卡动作

2. 刷卡时自动向采集器发送10位卡号（学号）

3. 充电过程中能够实时从采集器获取充电参数：电流电压温度，和电池电量，并正确显示。

4. 充满或用户主动停止则结束充电，并通知采集器。当电池电量大于电池容量99%以上时则认为充满。

5. 充电过程中出现过温/过流/过压等异常，立即报警，并通知采集器

## 充电参数采集器功能:

1，能够接收控制器发送的启动充电，刷卡，和停止充电命令

2，收到刷卡命令后，进入充电状态。充电时先恒流后恒压。

电池电量按电池容量\*（1-exp(-t/2)）自动变化。exp为e指数函数。t为刷卡后的时间，单位为s。

在电池电量小于容量80%时，采用恒流充电模式。电池电量超过容量80%时采用恒压充电模式。

恒流充电模式时：充电电流设定为电流最大值的2/3。

恒压充电模式时：充电电压设定为电压最大值的2/3。

3，采集器能够手动或自动设定设定充电参数。

4，在充电状态中，能够接收控制器查询充电参数命令，并回传充电参数

5，在充电状态中，能够一键设定一种或多种报警：过压，过流，或高温。

## 分组：2\~4人1组

## 评分组成：作品60分 +设计报告40分

## 一. 作品（小组）60分:

1. 界面设计：20%

2. 系统功能完成情况：40%

3. 通信协议设计：40%

3. 模块测试情况：20%（个人）

4. 系统调试情况：20%

5. 系统实现情况：10%
